Propuesta de Valor — Venezuela
💰
0% de comisión para el conductor. El conductor recibe el 100% de la tarifa en cada viaje. InDriver, Yummy y similares cobran 15–20%. El conductor gana más con VERONA aunque la tarifa al pasajero sea igual o menor.
💲
Precios en USD + Bolívares. La tarifa se calcula en dólares y se muestra en ambas monedas usando la tasa BCV oficial, actualizada cada hora automáticamente.
🧷
Membresía semanal en lugar de comisión. El conductor paga una membresía fija por semana (Moto $15 · Sedán $25 · SUV $35) y todos sus viajes son 100% suyos. Sin porcentaje por carrera.
🗺
Negociación de precio en servicios de Carga. El pasajero propone un precio, el conductor puede aceptar, rechazar o contra-ofertar con justificación. Flujo completo en tiempo real.

Servicio de Carga — Flujo Completo

El servicio de Carga agrupa 4 sub-tipos bajo una sola tarjeta en el menú del pasajero. Todos comparten el mismo formulario completo de entrega.

Sub-tipoMultiplicadorUso típico
🛻 Pick-Up×1.20Mudanzas ligeras, materiales de construcción, compras grandes
🚛 Plataforma×1.60Vehículos varados, cargas industriales planas
🛻 F-350 / Platabanda×2.0 (base negociación)Carga pesada, voluminosa — precio negociable
🚚 NPR 400+ / Camión×2.5 (base negociación)Carga industrial pesada — precio negociable
📋
Formulario de entrega unificado para todos los sub-tipos: dirección de recogida personalizada (con geocodificación), tipo de carga (descripción libre), precio ofrecido (ajuste ±$1), datos de quien entrega (nombre + teléfono), datos de quien recibe (nombre + teléfono).
🤝
Negociación F-350 / NPR: pasajero propone precio → conductor puede Aceptar, Rechazar o enviar Contra-oferta con nuevo precio y motivo → pasajero recibe modal y decide. Todo en tiempo real vía Socket.io.

Registro del Conductor — Venezuela

Flujo de 8 pasos con documentación venezolana obligatoria. No puede conectarse sin completarlo y ser aprobado por el admin.

PasoDatos requeridos
1. IdentidadNombre, foto de perfil, Cédula venezolana (V- / E-), foto del frente de la cédula, estado donde opera
2. LicenciaNúmero, fecha de vencimiento, foto de frente y dorso
3. Tipo de vehículoMoto / Sedán / SUV — determina la membresía y los tipos de servicio disponibles
4. Datos del vehículoMarca, modelo, año, color, número de placa
5. SeguroPóliza de seguro (PDF o foto), fecha de vencimiento
6. Fotos del vehículoFrente, trasera, laterales, interior (9 fotos)
7. CertificacionesPrimeros auxilios, manejo defensivo, otros módulos de capacitación
8. RevisiónResumen de todo y envío para aprobación del admin
📋
El conductor puede cambiar el tipo de vehículo después del registro desde el menú principal (ej. actualizar de Sedán a SUV). El cambio actualiza la membresía correspondiente.

Seguridad y Emergencias
🚨
Botón SOS — Pasajero y Conductor
Mantener presionado 2 segundos para activar (evita activaciones accidentales). Alerta al admin vía Socket.io y FCM con coordenadas GPS e ID del viaje. Vibración háptica.
🗺
Alerta de Desvío de Ruta
Si el conductor se desvía más del 20% de la ruta original, el pasajero recibe alerta automática con indicación de usar el SOS si se siente inseguro.
⚡
Monitoreo de Velocidad
Seguimiento GPS de velocidad en tiempo real durante el viaje. Alerta al conductor si supera el límite configurado. Cooldown de 30 segundos entre alertas.
🎙
Grabación de Audio del Viaje
El pasajero puede grabar el viaje completo. El audio se almacena localmente en el dispositivo. Nunca se sube a ningún servidor.
📸
Verificación de Foto del Pasajero
Obligatoria antes del primer viaje. El conductor ve la foto antes de confirmar la recogida. Almacenada en Supabase Storage con URL firmada.
🔗
Seguimiento en Vivo Compartible
El pasajero genera un link público de seguimiento válido 2 horas. Un familiar puede ver la ubicación del conductor sin tener la app instalada.

Infraestructura y Tecnología

Stack Tecnológico

  • Backend: Node.js 20 + Express + TypeScript 5.3 · Railway
  • Base de datos: PostgreSQL 15 + PostGIS 3 (Supabase)
  • Tiempo real: Socket.io 4.7 con Redis Pub/Sub (escalable)
  • Caché: Redis 7 (Railway) — GPS 10s TTL, tarifas 1h
  • Auth: Firebase Auth (email/Google/Apple) + JWT custom 2h + Refresh 30 días
  • Push: Firebase Cloud Messaging (FCM)
  • Storage: Supabase Storage (documentos, fotos — URLs firmadas)
  • Mapas: Google Maps Platform (distancias, geocodificación, rutas)
  • Tasa BCV: Fetch automático cada hora via API
  • Mobile: React Native 0.81.5 + Expo SDK 54
  • Dashboard: Next.js 16 + TailwindCSS · Vercel

Seguridad

  • HTTPS enforced (Railway + Vercel) + HSTS 1 año
  • AES-256-GCM para columnas PII en base de datos
  • JWT Bearer token + Refresh rotation
  • RBAC: pasajero / conductor / admin
  • Row Level Security (RLS) en Supabase
  • Rate limiting: 100 req/min general, 5 intentos fallidos login
  • Winston logging con redacción automática de PII (emails, GPS, teléfonos)
  • Helm CSP, X-Frame-Options, X-Content-Type
  • Admin 2FA TOTP (Google Authenticator)
  • GDPR data export — endpoint portabilidad de datos

Deploy

  • Backend: Railway (auto-deploy en git push)
  • Dashboard: Vercel (auto-deploy en git push)
  • Mobile: Expo EAS Build (APK Android + iOS)
  • BD: Supabase (backups automáticos diarios, 30 días)
  • 38+ migraciones SQL aplicadas
